# TDG Configuration

## Project Information
- Language: JavaScript (ES modules)
- Framework: Vanilla HTML/CSS/JS (calculator web page)
- Test Framework: Vitest (with jsdom for DOM tests)

## Build Command
npm install

## Test Command
npx vitest run

## Single Test Command
npx vitest run <path/to/file.test.js> -t "<test name>"

## Coverage Command
npx vitest run --coverage

## Test File Patterns
- Test files: *.test.js
- Test directory: tests/
